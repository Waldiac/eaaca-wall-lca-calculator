# EAACA Wall LCA Calculator

Web-based life-cycle assessment tool for wall constructions developed for EAACA.

**Current version:** V6_2026

## Live tool

https://waldiac.github.io/eaaca-wall-lca-calculator/

## Purpose

The tool allows the environmental performance of wall constructions to be calculated and compared on a layer-by-layer basis.

It includes life-cycle modules from production through end-of-life and benefits beyond the system boundary, based on the data available for the selected construction materials.

Main functions include:

- layer-based wall construction
- calculation of life-cycle module contributions
- A–C total results
- module-resolved charts
- comparison of multiple constructions
- save/load functionality in the browser
- JSON import/export
- printable report generation

## Technical information

The application is a self-contained HTML/JavaScript web application and does not require a backend or external database.

## Disclaimer

The tool is intended to support comparative assessment and technical analysis. Results depend on the material and environmental data used and should be checked against the relevant EPDs and applicable standards for project-specific use.
